服务标识来自 service_registry

服务是谁、代码在哪。以注册中心登记为准，本机不能改。

运行目录按目标机器平台选

部署把制品 rsync 到这里、在这里跑 restartCmd。默认给本机平台用；macOS / Linux 机器可以各配一份。

服务接口URL 只填路径

端口必填（启动时注入 SERVICE_PORT）；探活与 graceful 只填路径，host:port 在部署时按目标机器拼。

本机监督agent-watchdog

勾选后，本机 watchdog 按上面的端口 / healthUrl / 启停命令探活，DOWN 时执行 startCmd。探活周期由本页统一下发，watchdog 对账时覆盖本地默认值。不勾选则只部署、不自动拉起。

启停命令在目标机器上执行

部署时在运行目录里执行 restartCmd，并注入 SERVICE_PORT / APP_VERSION / DEPLOY_MACHINE / RUNTIME_DIR。
